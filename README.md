# 🧠 Projeto de Análise de Dados com Python

Este repositório documenta meu aprendizado e prática em **Python voltado para análise de dados**, utilizando **NumPy** e **Pandas** como principais ferramentas.  
O projeto faz parte do meu curso de **Python para Dados**, com foco em manipulação, limpeza e visualização de informações.

---

## 🚀 Objetivo
Explorar o poder do Python para transformar dados brutos em insights úteis, aplicando técnicas de:
- Manipulação de arrays e matrizes com **[NumPy](ca://s?q=Aprender_NumPy)**
- Tratamento e análise de dados tabulares com **[Pandas](ca://s?q=Aprender_Pandas)**
- Visualização com **[Matplotlib](ca://s?q=Aprender_Matplotlib)** e **[Seaborn](ca://s?q=Aprender_Seaborn)**

---

## 🧩 Ambiente de Desenvolvimento
- **Sistema:** Kali Linux  
- **Gerenciador:** Anaconda  
- **Editor:** VSCode / Jupyter Notebook  
- **Versão do Python:** 3.12  

### 📦 Bibliotecas principais
| Biblioteca | Função |
|-------------|--------|
| **NumPy** | Operações matemáticas e vetorização |
| **Pandas** | Manipulação e análise de dados |
| **Matplotlib** | Gráficos e visualizações |
| **Seaborn** | Visualizações estatísticas |
| **Jupyter Notebook** | Ambiente interativo para experimentos |
